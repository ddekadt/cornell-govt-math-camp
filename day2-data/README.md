# Day 2 teaching data

**These numbers are simulated.** The country names, ISO codes and regions
are real; everything else was generated by `make-data.R` with
`set.seed(2026)`. It is shaped like a World Bank country-year panel and is
useful only for teaching — never cite anything from it.

## Files

| File | Contents | Rows |
|---|---|---|
| `data/raw/trade-panel.csv` | 12 countries × 1995–2020: GDP, population, exports, incumbent vote share | 312 |
| `data/raw/regime.csv` | regime type and EU membership — the lookup table to join on | 12 |
| `data/raw/gdp-wide.csv` | the same GDP figures in wide form, for the pivot demo | 12 |
| `make-data.R` | regenerates all three. Base R only, no packages needed. | — |

## Columns in `trade-panel.csv`

| Column | Type as written | Meaning |
|---|---|---|
| `iso3` | text | ISO 3-letter code — **the good join key** |
| `country` | text | country name — a bad join key, see below |
| `region` | text | Africa / Americas / Asia / Europe |
| `year` | number | 1995–2020 |
| `gdp_bn` | number | GDP, billions USD |
| `pop_mn` | **text** | population, millions — see problem 2 |
| `exports_bn` | number | exports, billions USD |
| `Vote Share` | number | incumbent vote share, % |

## The five planted problems

Each one exists to demonstrate a specific point in the Day 2 script. Nothing
here is accidental.

**1. `-99` as a missing-value code.** 9 rows in `gdp_bn`. `summary()` shows
a minimum of −99, and an economy cannot be negative. Fixed with
`na_if(gdp_bn, -99)`.

**2. `pop_mn` reads as text.** Thousands separators (`"1,001.1"`), World
Bank missing markers (`".."`, 5 cells), and footnote asterisks (`"222.7*"`,
4 cells). `read_csv()` reports it as `chr`. Fixed with `parse_number()`,
which warns about exactly the 5 it cannot read — a good chance to say that
a warning is often good news.

**3. A column name with a space:** `Vote Share`. Needs backticks to
reference. Fixed with `rename(vote_share = \`Vote Share\`)`.

**4. Country names spelled differently across files.** `regime.csv` uses
`"Korea, Rep."`, `"Germany, Fed. Rep."`, `"Turkiye"`, `"USA"` — all real
spellings used by real data providers. Joining on `country` silently loses
5 countries; `anti_join()` finds them.

**5. A duplicated key, and a missing one.** `KOR` appears twice in
`regime.csv`, so a naive `left_join()` on `iso3` turns 312 rows into **338**
(dplyr also warns about a many-to-many relationship). `IDN` is absent
entirely, so `left_join()` keeps Indonesia's rows with `NA` in the new
columns while `inner_join()` would drop 26 rows without a word.

There are also 6 genuinely blank cells in `Vote Share`, so that `drop_na()`
removes more rows (20) than dropping only missing GDP would (9).

## Regenerating

```r
source("make-data.R")     # writes all three files into data/raw/
```

The seed is fixed, so you get identical files every time. Edit the script if
you want different countries, a different span of years, or different
problems planted.
